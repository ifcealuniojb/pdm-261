# Avaliação 07 — Layout responsivo animado

Aplicativo Flutter de mensagens desenvolvido a partir da [etapa final do CodeLab oficial](https://codelabs.developers.google.com/codelabs/flutter-animated-responsive-layout?hl=pt-br#0). O layout usa Material 3, troca a barra inferior por uma barra lateral em telas largas e anima a transição entre os formatos. Os personagens, as conversas e a interface foram adaptados para português do Brasil. No Android, o app aparece como **Atividade 07**, com um ícone de envelope.

## Executar no Android

1. Conecte um celular Android com a depuração USB ativada e autorize o computador no aviso do aparelho.
2. Nesta pasta, execute `flutter pub get` e `flutter devices`.
3. Execute `flutter run -d <ID_DO_DISPOSITIVO>`.

## Verificação

`flutter analyze` e `flutter test` verificam o projeto. A captura em [`screenshots/moto-g32.png`](screenshots/moto-g32.png) foi obtida no Moto G32 com o app em execução.
